Comet is an offline payment solution that leverages the power of blockchain. This project was selected as the top 4 at Blockchain category in UnitedByHCL Hackathon 2017. Comet consists of an Android app which was built with Kotlin, a frontend web which was built with React, a backend which was built with Node.js, and a blockchain network which was built with Ethereum test network.
