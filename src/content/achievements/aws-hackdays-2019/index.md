My team won the 1st place in AWS Hackdays 2019 Indonesia and secured the 3rd place in AWS Hackdays Grand Final in Singapore. We built two products for this competition. Aident, a real-time crime activity detection and criminals face recognition system. The second one is Eyve which is built to protect people with visual impairments in daily life.
